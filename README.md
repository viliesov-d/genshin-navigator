# Genshin Navigator

Нативний помічник для Windows 10/11, який показуватиме інформацію про дослідження світу Genshin Impact поверх вікна гри. Проєкт розвивається поетапно, а інтерфейс не показує вигадані координати чи маркери.

## Поточний стан

**Етап B — прототип розпізнавання мінікарти.** Після вибору локального скриншота відкритої карти програма знімає область мінікарти з видимих пікселів і шукає відповідний фрагмент через ORB feature matching та RANSAC. Результат показується як координата в обраному скриншоті з оцінкою збігу.

Початковий режим роботи — віконний або borderless. Ексклюзивний повноекранний режим не перевірявся.

Цей етап є прототипом: він не переводить координату у глобальні координати світу, не відстежує рух між різними скриншотами карти та ще не має бази маркерів, відстані до цілі, стрілки навігації чи прогресу. Для першої перевірки потрібен скриншот карти тієї самої області, що зараз видна на мінікарті. Краще зробити його на близькому масштабі та без великих меню поверх карти.

## Збірка у Windows

Потрібен .NET 8 SDK та Windows 10/11.

```powershell
dotnet run --project .\GenshinNavigator\GenshinNavigator.csproj
```

Щоб зібрати portable x64 версію:

```powershell
dotnet publish .\GenshinNavigator\GenshinNavigator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

GitHub Actions автоматично збирає застосунок на Windows та додає папку publish як артефакт запуску workflow. Для цього не потрібен встановлений .NET на комп'ютері користувача.

## Перший запуск розпізнавання

1. Увійдіть у світ гри у віконному або borderless режимі.
2. Відкрийте карту світу та зробіть власний скриншот ділянки, де зараз перебуває персонаж.
3. У панелі відкрийте ⚙, натисніть **Обрати…** біля «Скриншот карти для зіставлення» та виберіть файл.
4. Збережіть налаштування. Панель періодично зіставлятиме мінікарту зі скриншотом і показуватиме координату та кількість узгоджених точок.

Тримайте панель подалі від мінікарти. Захоплення та аналіз виконуються локально; кадри не зберігаються і не надсилаються мережею. Наразі рекомендована роздільність 16:9. Повноекранний ексклюзивний режим не перевірений.

## Безпека та обмеження

- Програма перевіряє лише назву запущеного процесу гри.
- Для позиції використовуються тільки видимі пікселі ігрового вікна та файл карти, який вибирає користувач.
- Вона не читає/змінює пам'ять гри, не інжектує код, не модифікує файли гри й не автоматизує ігрові дії.
- Робота стороннього overlay не має офіційної гарантії схвалення HoYoverse. Використовуйте його на власний розсуд.

## Стороння бібліотека

Зіставлення зображень використовує OpenCvSharp4 та OpenCV 4.13 під ліцензією Apache-2.0 (`4.13.0.20261107`). Для захоплення видимих пікселів застосовується System.Drawing.Common 8.0.34 (MIT).

## План реалізації

1. **Основа:** overlay, параметри, визначення запущеної гри — готово.
2. **Прототип координат:** локальне зіставлення мінікарти зі скриншотом — у роботі.
3. **Координати світу:** перевірка різних областей і масштабів, стабільне відстеження руху.
4. **Дані:** ліцензоване джерело маркерів, категорії та локальне кешування.
5. **Навігація:** найближча незнайдена ціль, напрямок, відстань і відкриття джерела.
6. **Карта:** зовнішній графічний шар із фільтрами та позначками.
7. **Завершення:** збереження прогресу, резервні копії та Windows-пакування.

Кожна наступна функція буде позначена як готова лише після перевірки на реальних контрольних зображеннях і даних.
