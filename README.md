# Genshin Navigator

Нативний помічник для Windows 10/11, який показуватиме інформацію про дослідження світу Genshin Impact поверх вікна гри. Проєкт розвивається поетапно, а інтерфейс не показує вигадані координати чи маркери.

## Поточний стан

**Етап A — основа overlay (у розробці).** У першій гілці реалізуються плаваюча WPF-панель, переміщення й блокування позиції, налаштування прозорості та масштабу, локальне збереження параметрів, а також перевірка наявності процесу гри за його назвою.

Поки що визначення координат, база об'єктів, відстань, стрілка до цілі, інтерактивна карта та прогрес не реалізовані. У вікні чесно показується «Позицію ще не визначено», а навігація вимкнена.

## Збірка у Windows

Потрібен .NET 8 SDK та Windows 10/11.

```powershell
dotnet run --project .\GenshinNavigator\GenshinNavigator.csproj
```

Щоб зібрати portable x64 версію:

```powershell
dotnet publish .\GenshinNavigator\GenshinNavigator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\publish
```

GitHub Actions автоматично збирає застосунок на Windows та додає папку publish як артефакт запуску workflow. Для цього не потрібен встановлений .NET на комп'ютері користувача.

## Безпека та обмеження

- Програма перевіряє лише назву запущеного процесу гри.
- Вона не читає/змінює пам'ять гри, не інжектує код, не модифікує файли гри й не автоматизує ігрові дії.
- Робота стороннього overlay не має офіційної гарантії схвалення HoYoverse. Використовуйте його на власний розсуд.

## План реалізації

1. **Основа:** overlay, параметри, визначення запущеної гри.
2. **Дані:** перевірене джерело маркерів, категорії та локальне кешування.
3. **Координати:** калібрування карти й визначення позиції з індикатором достовірності.
4. **Навігація:** найближча незнайдена ціль, напрямок, відстань і відкриття джерела.
5. **Карта:** зовнішній графічний шар із фільтрами та позначками.
6. **Завершення:** збереження прогресу, резервні копії та Windows-пакування.

Кожна наступна функція буде позначена як готова лише після перевірки на реальних контрольних зображеннях і даних.
